# vivasam2core

비바샘 문제은행에서 내려받은 문제 파일(HWP로 저장된 HWPML)을
직접 만든 CORE 교재 서식(예: `2-1 교정적 정의(심화)(답지).hwp`)으로 바꿔 주는 변환기입니다.
결과물은 한글에서 바로 열 수 있는 HWP 5.x 파일입니다.

## 사용법

```bash
pip install -r vivasam2core/requirements.txt
python -m vivasam2core -t "2-1 교정적 정의(심화)(답지).hwp" -o output --student 비바샘파일1.hwp 비바샘파일2.hwp
```

- `-t` : 서식 원본(템플릿) HWP. 용지·2단·머리말·바탕쪽·글꼴·상자 모양을 여기서 가져옵니다.
- `-o` : 결과 폴더 (기본값 `output`)
- `--student` : 정답 표시가 없는 문제지 버전도 함께 만듭니다.
- `--title` : 머리말 "실전 문제" 뒤 제목 (기본값: 비바샘 파일의 과목명, 예: `경제`)

결과 파일 이름: `비바샘 <과목(저자)>(심화)(답지).hwp`, `비바샘 <과목(저자)>(심화).hwp`

## 변환 규칙

| 비바샘 원본 | 변환 결과 (템플릿 서식) |
| --- | --- |
| 문제 번호 | 템플릿의 자동 번호 문단(개요 번호, 기울임 굵은 번호) |
| 지문 상자 | 템플릿의 1×1 지문 상자 (그림은 가운데 정렬) |
| (가)/(나) 지문 | 왼쪽에 (가)/(나) 칸이 있는 템플릿의 2열 표 |
| `<보기>` | 템플릿의 "< 보기 >" 상자, 조합형 선지(① ㄱ, ㄴ …) 삭제, 발문을 "있는 대로 고른 것은?"으로 |
| `<핵심어>`, `<조건>` 등 | "< 보기 >" 상자와 같은 모양, 제목만 바꿈 |
| 선지 | 5행답항 스타일 `① …` (짧은 선지는 한 줄) |
| 조합형 선지(① A, B … / ① 갑, 을 …, <보기> 없음) | 선지 삭제, 발문 "있는 대로 고른 것은?", 지문의 정답 줄(`A:`, `갑:` …)을 빨강으로 |
| 연결형 선지 표 | 같은 글꼴의 표, 정답 행 빨강 |
| 답지 | 정답 선지·정답 <보기> 항목을 빨강으로, 서술형은 `답:` / `예시 답안:`을 빨강으로 |
| 해설·채점 기준 | 템플릿(답지)에 없으므로 넣지 않음 |

## 한글에서 고친 답지 후처리

- `python -m vivasam2core.prune 입력.hwp 출력.hwp` – 발문에 "(삭제)"라고 적은 문제를 해설·정답표와 함께 지우고 번호를 다시 맞춥니다.
- `python -m vivasam2core.markcombo 입력.hwp 출력.hwp` – 조합형 선지(① A, B …)를 지우고 지문의 정답 줄을 빨강으로 표시, 정답표·해설의 정답도 `A, D`처럼 바꿉니다. 선지를 이미 지운 문제는 빨강으로 칠해 둔 줄을 정답으로 봅니다.

## 구성

- `vivasam.py` – 비바샘 HWPML 파서 (문항·지문·보기·선지·정답 분리)
- `convert.py` – 템플릿 서식으로 배치하는 변환 규칙
- `hwpbuild.py` – HWP 문단/표/그림 레코드 생성, 템플릿 표 복제
- `docinfo.py` – 글자·문단 모양, 그림 목록(BinData) 추가
- `hwp5.py`, `cfb.py` – HWP 레코드 입출력과 OLE 복합 문서 쓰기
- `layout.py` – 줄 나눔 추정(한글이 파일을 열 때 다시 계산함)
